# Lo básico de Google Colab

Google pone a nuestra disposición una herramienta gratuita que nos permite ejecutar código Python y R en la nube, sin necesidad de instalar nada en nuestro equipo. Esta herramienta se llama Google Colab y es especialmente útil para tareas de análisis de datos, aprendizaje automático y desarrollo de modelos de inteligencia artificial entre otras funciones.

Para realizar esto se utilizará un entorno de notebooks, similar a Jupyter Notebook, donde podemos escribir y ejecutar código en celdas, así como agregar texto explicativo y visualizaciones, dicho notebook puede ser descargado y subido a Google Colab para su ejecución.

De todos modos se incluirán referencias a la documentación oficial de Google Colab para aquellos que deseen profundizar en el tema.
