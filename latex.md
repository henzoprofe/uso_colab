# $\LaTeX$

Para escribir expresiones matemáticas es posible escribirlas utilizando $\LaTeX$, y la forma de hacero es la siguiente:
```text
$acá va el código$
```
Algunas cosas escritas en $\LaTeX$
```text
$\displaystyle \sqrt{x}$

$$\displaystyle frac{x^4-16}{x^2-4}$

$\displaystyle \sqrt{\frac{\sum_{=1}^{n} {f_i \cdot (x -  \overline{x})}}{n}}$

$\displaystyle (a+b)^n = \sum_{k=0}^{n} \binom{n}{k}a^n b^{n-k}$
```
se ven así

$\displaystyle \sqrt{x}$

$\displaystyle \frac{x^4-16}{x^2-4}$

$\displaystyle \sqrt{\frac{\sum_{=1}^{n} {f_i \cdot (x -  \overline{x})}}{n}}$

$\displaystyle (a+b)^n = \sum_{k=0}^{n} \binom{n}{k}a^n b^{n-k}$

como se puede apreciar, las opciones son muchas, pero requieren un conocimiento extra.

Aunque existen páginas en las que se puede hacer click sobre los símbolos y generar el código para pegarlo en el notebook en caso de considerar que la escritura directa se complica.
