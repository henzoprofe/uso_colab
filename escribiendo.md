# Utilizando lasceldas de texto

Como se vió en **"Iniciando"**, existen dos tipos de celdas en un notebook, las celdas de texto y las celdas de código, y su nombre nos dice que hace cada una de ellas.
LAs celdas de texto admiten tres formas de escritura en código para producir resultados visualmente agradables, estos tres tipos de escritura son:

- Markdown: es el formato nativo u original de las celdas de texto en los notebooks. [PINCHA AQUÍ](https://markdown.es/sintaxis-markdown/) para ir a una página de manual para ver las opciones que presenta el formato Markdown.

- HTML: es una forma de escribir muy extendida, y tambien confundida, pues algunos dicen que es un lenguae de programación, aunque en verdad no lo es, es un **lenguaje de marcado de hipertexto** que no tiene lógica, ni variables, ni funciones, ni estructuras de control de flujo, que son las funciones básicas de todo lenguaje de programación que se respete debe tener. Su nombre viene de la sigla en inglés para **Hyper Text Markup Language**. [PINCHA AQUÍ](html.md) para ir a una página de manual donde verás lasopciones más utilizadas de HTML en un notebook.

- $\LaTeX$: es un **sistema de composición de textos** que permite crear textos con calidad tipográfica profesional, aunque nosotros lo utilizaremos simplemente para escribir expresiones matemáticas, para utilizar $\LaTeX$ en una celda de texto, su código se debe encerrar entre signos de dinero ($). [PINCHA AQUÍ](latex.md) para ir a una página de manual con las opcionesmás comunes para escribir expresiones matemáticas.

Los notebooks en realidad tienen soporte nativo a otras formas de escritura, pero para nuestros intereses, con estos tres es más que suficiente.
